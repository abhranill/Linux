Welcome to my Linux Learning Repository! 🐧

This repository documents my journey of learning Linux, understanding command-line tools, practicing shell commands, and exploring system administration and cybersecurity fundamentals.

The goal is to build a strong foundation in Linux through hands-on practice, practical examples, and consistent learning.

🎯 Learning Objectives

- Understand Linux fundamentals and its architecture.
- Master essential Linux terminal commands.
- Learn file and directory management.
- Understand Linux permissions and ownership.
- Practice process and system management.
- Learn Bash scripting and automation.
- Explore networking commands and utilities.
- Understand Linux security fundamentals.
- Build a foundation for ethical hacking and cybersecurity.

📚 Topics Covered

1. Linux Fundamentals

- Introduction to Linux
- Linux distributions
- Linux file system hierarchy
- Terminal and shell basics
- Absolute and relative paths

2. Basic Linux Commands

Command| Description
"pwd"| Display the current directory
"ls"| List files and directories
"cd"| Change the current directory
"mkdir"| Create a directory
"touch"| Create an empty file
"cp"| Copy files and directories
"mv"| Move or rename files
"rm"| Remove files and directories
"cat"| Display file contents
"clear"| Clear the terminal
"man"| Open a command's manual
"whoami"| Display the current username

3. File Permissions and Ownership

- Read, write, and execute permissions
- "chmod" — Change file permissions
- "chown" — Change file ownership
- "sudo" — Execute commands with elevated privileges
- Understanding users and groups

4. Process and System Management

- "ps" — Display process information
- "top" — Monitor running processes
- "kill" — Send signals to processes
- "free" — Display memory usage
- "df" — Check disk space
- "du" — Check file and directory sizes
- "uptime" — Display system uptime

5. Package Management

- Installing and removing software
- Updating system packages
- Understanding package managers
- Working with APT on Debian-based distributions

6. Networking Basics

- "ip" — View and manage network interfaces and addresses
- "ping" — Test network connectivity
- "ss" — Inspect network sockets
- "curl" — Transfer data using URLs
- "wget" — Download files from the web
- "traceroute" — Investigate network paths

7. Bash Scripting

- Variables and user input
- Conditional statements
- Loops
- Functions
- Command-line arguments
- Automating repetitive tasks

8. Linux for Cybersecurity

- Understanding system security
- User and permission management
- Log file analysis
- Basic network troubleshooting
- Introduction to security tools
- Practicing in authorized lab environments
